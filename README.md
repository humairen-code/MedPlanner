# MedPlanner
by Huma and Sri Sai

# Description

This project is meant to be used as a medicine tracker/planner for any person. When you open the website, there will be a calendar view in front of you with tabs to add or edit medications based on your personal requirements.  
It will be very customizable with a chance to change colors, fonts, and the layout of the weekly calendar based on preferences. Once you take the medication, you can check it off.
